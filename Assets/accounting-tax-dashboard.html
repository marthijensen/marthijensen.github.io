Project Overview

This project demonstrates how related financial tables can be transformed into a clear reporting experience for reviewing income, deductions, credits, tax estimates, payments, refunds, and amounts due.

◎

Goal

Create a financial analytics dashboard that turns multiple tax-related data tables into a clear, interactive reporting experience.

⌘

Challenge

Financial information can be difficult to interpret when data is spread across income, deductions, credits, and tax summary tables.

↗

Solution

Built a three-page Power BI dashboard with executive summaries, anonymous profile analysis, and comparative tax insights.

Dashboard Experience

The report is organized into three views that move from high-level financial performance to filtered analysis and grouped trends.

Page 01

Executive Overview

A high-level summary that helps users quickly understand income, deductions, credits, estimated tax, refunds, amount due, and effective tax rate across filing-status groups.

  • Financial KPI cards for core tax metrics
  • Income and taxable-income comparisons by filing status
  • Deduction composition and refund-versus-amount-due views
  • Grouped summary table without client names

Project Process

The dashboard was designed by connecting related data tables, creating reusable DAX measures, and organizing visuals around practical financial questions.

Step 01

Prepared the Data

Loaded Excel tables for clients, income, deductions and credits, and tax summary records into Power BI.

Step 02

Built the Model

Used Client ID relationships to connect the main dimension table to income, deductions, and tax summary tables.

Step 03

Created DAX Measures

Calculated income, deductions, credits, taxable income, tax, payments, refunds, amount due, and effective tax rate.

Step 04

Designed for Clarity

Built pages for executive review, detailed anonymous analysis, and broader financial insight discovery.

Data Model & Methodology

The Power BI semantic model connects separate financial tables through a central client dimension while keeping reporting fields organized and reusable.

Core Data Tables

The project uses four main Excel tables to represent the financial profile, income activity, deductions and credits, and final tax outcomes.

  • ▣ ClientsTable — filing status, state, dependents, and profile attributes
  • ▣ IncomeTable — wages, business income, interest, dividends, and capital gains/losses
  • ▣ DeductionsCreditsTable — deduction categories and tax credits
  • ▣ TaxSummaryTable — taxable income, tax estimates, payments, refunds, and balances due

Key Measures Created

DAX measures were created to support consistent calculations across all pages of the report.

  • ✓ Total Income and Total Taxable Income
  • ✓ Total Deductions and Total Credits
  • ✓ Estimated Tax and Total Payments
  • ✓ Refund Amount and Amount Due
  • ✓ Average Effective Tax Rate
Confidentiality-aware reporting: This dashboard intentionally avoids displaying client names in its overview and insight views. The detailed page uses anonymous profile identifiers and grouped filters to demonstrate responsible handling of financial information.
