The Challenge

Financial information is easier to use when it has one clear story.

Income, deductions, credits, tax liability, and payment outcomes can be difficult to compare when they live in separate tables or spreadsheets.

This project organizes those connected records into a report that supports both quick executive review and deeper tax-profile exploration.

What I Built

A focused three-page reporting experience.

Each page has a distinct purpose, so users can move from a broad financial picture to detailed and comparative analysis without losing context.

3 pages Executive, detail, and insight views
7 KPIs Income, deductions, tax, refunds, and more
5 filters Tax-profile exploration controls
Client detail Individual records with financial context

My Process

From structured data to a usable financial report.

I focused on making the report technically connected, visually consistent, and easy for a nontechnical user to navigate.

  1. 01 Prepared data Organized income, deduction, credit, and tax-summary records.
  2. 02 Built relationships Connected related tables for consistent filtering and reporting.
  3. 03 Created measures Calculated core financial, tax, refund, and amount-due metrics.
  4. 04 Designed pages Created executive, detail, and comparative insight views.
  5. 05 Refined clarity Applied financial formatting, hierarchy, labels, and spacing.

Portfolio Note: This dashboard uses protected, anonymized, or simulated data for learning and portfolio purposes. It does not provide tax advice or display confidential client information.
